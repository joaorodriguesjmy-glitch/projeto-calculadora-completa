# Calculadora Simples

Aplicação desktop em Python com interface gráfica (`tkinter`) para realizar as quatro operações matemáticas básicas (`+`, `-`, `*`, `/`) entre dois números.

## Funcionalidades

- Suporte a números inteiros e decimais (`float`).
- Operações de **adição (`+`)**, **subtração (`-`)**, **multiplicação (`*`)** e **divisão (`/`)** implementadas com `match`/`case`.
- Validação de entradas inválidas e bloqueio de **divisão por zero** com caixas de alerta (`messagebox`).
- Utiliza apenas módulos nativos do Python (`tkinter`), sem necessidade de instalar bibliotecas externas.

## Como executar

1. Certifique-se de ter o **Python 3.10+** instalado no computador (devido ao uso de `match`/`case`).
2. Abra a pasta do projeto no **VS Code**.
3. Execute o arquivo `calculadora_simples.py` clicando em **Play** (`▷`) ou rodando no terminal:
   ```bash
   python calculadora_simples.py
